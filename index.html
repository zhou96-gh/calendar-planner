    节假日数据

    已载入 2026 年官方安排

    节日日期在本地计算。这里可导入、导出法定假期安排，或重置指定年份的数据。

    重置会重新获取该年的官方安排，并清理该年的日期修正、个人调休和补班；其他年份和设置保留。获取失败时不清理原数据。

    假期安排 JSON 结构 
    {
  "version": 7,
  "holidayData": {
    "blocks": [{
      "startDay": "2026-10-01", "endDay": "2026-10-03",
      "name": "示例假期", "legalDays": 2, "makeupDays": 1,
      "dates": ["2026-10-01", "2026-10-03"]
    }],
    "days": { "2026-09-25": { "kind": "legal", "name": "中秋节" } }
  },
  "loadedYears": [2026]
}

    导入会替换文件涉及年份的全部假期安排及日期修正，保留其他年份、设置、配色和个人调班。version 必须为 7，旧版本文件不支持；原完整备份仅提取假期安排。

    holidayData
    blocks 为节假日区间；dates 可选，仅保留区间中指定的日期。不在区间内的修正日期放在 days，类型为 legal/off/work。
    loadedYears
    文件已载入年份，可省略；导入只替换实际包含日期的年份。全部日期使用 YYYY-MM-DD。

    也支持直接导入 holiday-cn 年度 JSON：包含 year 和 days，每项为 { "date": "2027-01-01", "name": "元旦", "isOffDay": true }。空年度数据不能导入。
