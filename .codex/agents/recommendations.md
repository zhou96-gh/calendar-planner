# 休假推荐

## 公共方案与页面

- 点击假日侧栏打开休假推荐，表格分列展示方案、休假、调休、补班、统计及操作；调休列包含免补班假期，补班日期单独一列，日期列只显示日期，统计列汇总休假、调休、免补班假期、补班天数和最长连续上班。生成最早放假、最长假期、最短连续上班三类方案。可用方案的连续休假、调休、补班及免补班范围完全相同时，表格只保留最先出现的一项；不因名称不同重复展示，不合并安排不同但天数相同的方案，原策略标识及已采用组识别保持兼容。
- 方案最终保持一段连续休假，新增调休日不要求相邻；结合周末、法定及已有个人休假，只为上班缺口分配调休或额外免补班假期。不得因新增调休日被已有休息日隔开而排除候选，也不得把中间仍需上班的包络范围当作连休。
- 整数额度优先整天调休及整天补班，没有可用整天调班方案时才尝试半天；明确输入含 0.5 天的调休或免补班额度时直接按半天搜索，不先舍去小数部分，仍先尝试整天补班。补班在满足上班上限及月份配对的安排中优先最少半天日期，再优先上午半天，之后缩短连续上班；不能仅为缩短工作段把可用整天补班拆成半天，也不能为用满额度突破上班上限或月份配对。第三类在当前精度候选中先最小化最长工作段，同值时优先更长休假，再选择更少调班，允许保留零调班方案。
- 调休上限默认 4 天，约束单次推荐新增的需补班调休总天数，跨月合计一次，不逐月重置，也不扣减已有调班；跨月默认关闭，两项均支持页面临时覆盖。页面按可补班时段显示调休最大值并限制输入。沿用原配置字段及数值校验以兼容已保存设置和备份，不因历史字段名恢复逐月业务限制。最长上班上限只在本次生效，留空不限，最小及步长均为 0.5 天；约束三类方案，没有合规方案则标记不可用。
- 假期天数是页面临时配置，默认 0，按 0.5 天递增，作为调休之外的额外免补班额度。生成结果分别展示假期、调休及补班，新增休假不得超过调休上限与额外假期额度之和；方案假期天数为 0 时不显示对应汇总，页面说明也省略为 0 的额外假期配置，保留配置输入供修改。
- 休假始终可延伸至假期前后相邻月。“跨月”约束调休与补班的月份配对：关闭时每个月新增需补班调休与本月补班分别等量，可在多个自然月分别匹配，不按所点法定假期月份限制补班；开启后优先同月，无合规方案时只允许在一对相邻月份之间单向转移补班额度，不同时向前后两侧借用，按当前精度下距离调休日最近的可补班日期优先选月。
- 额外免补班假期不参与月份配对，根据实际各月可补班日期分配免费额度，避免固定把免费假期放在最前面而漏掉可行方案。已有方案的跨月配置由需要补班记录的逐月余额判断，不参考法定假日月份，也不把独立免补班记录算入。
- 调休最大值根据连续休假候选、额外假期、月份配对及页面最长上班上限核对补班容量，不简单累加两侧月份；复用推荐补班搜索验证可行性，留空上班上限时只核对容量。默认或已输入的额度超过容量时仅下调本次临时值，不保存为设置，容量回升时不自动抬高已下调的值。法定休假和已有个人调班不作为补班候选，假期内的原休息日不用于补班。
- 在满足同月优先及相邻月配对的条件下缩短最长连续工作段。工作按 0.5 天累计，任一休息时段均中断工作段，统计计入月边界；不能用收紧的搜索上限替代页面实际上限决定是否跨月，以免跳过原本可行的同月方案。
- 配置项横排，标签和控件不换行；推荐窗口使用紧凑控件，输入框高 28px，应用和取消按钮最小高度 26px，关闭按钮基准尺寸 24px，两端共用，字号不随紧凑排版缩小，普通控件高度不按密度额外缩放。推荐表格内休假、调休、免补班假期和补班共用日期汇总方式，按月份升序排列，同月整天、上午、下午分别一行。整天的连续日号在括号内合并为范围，如 `2027-02（1-6、8、10-12）`；半天始终逐日以顿号分隔，时段置于括号后，如 `2027-02（4、5）上午`。统计列各项沿用原休假天数的淡色小字样式，每行两项，免补班假期为 0 时隐藏该项；调休和免补班假期日期通过文字标签区分。每组日期保持完整一行，不再自动折行；宽度不足时通过配置栏和结果区域各自的横向滚动查看。
- 推荐表格下提供默认收起的“显示说明”，仅用日期示例和简短释义解释年月、整天日期范围、半天时段后缀及各统计项，不展开完整计算、配对或筛选规则。顶部规则和底部限制优先用简短公式表达，底部对应当前临时配置，免补班额度为 0 时省略该项；说明与两端公共模板共用，不重复实现计算规则。
- 配置栏横向滚动时保留上下内边距及控件最小高度，容纳输入框的焦点描边；窗口缩矮时配置栏不得被压缩，纵向滚动交由窗口内容区负责。
- 使用方案复用原调班表单，确认保存前不改变排班。混合方案在表单中预览免补班假期，与需补班记录同次原子保存为独立的不关联记录，避免产生补班欠额；仅假期的方案直接复用不关联表单。桌面设置缺列兼容增列，备份缺项使用默认值。
- 新采用的方案通过操作 ID 保存来源假期、方案类型和同组标识，完整 ID 不得超过现有 80 字符限制，两端备份保持原样。推荐页展示已采用状态及更换、取消入口；重算只排除本方案，更换确认保存时原子替换旧方案，取消或删除整次推荐一并移除同组调休、补班及免补班假期。没有推荐来源的历史普通调班不凭备注推断为推荐组。
- 右侧假日列表仅在该假日存在已保存的推荐组时于假日名称同行显示方案名称，不单独占行，更换及取消后同步更新；名称按推荐类型识别，不从用户可编辑的备注推断，未确认的表单不显示为已采用。
- 更换表单未保存时保留旧方案；提交前再次核对旧方案快照，旧方案已修改或取消时拒绝过期提交。推荐日期不得覆盖其他手动调班。取消不依赖年度加载，加载及参数校验失败时仍显示取消入口；独立窗口取消动作由主窗口等待提交队列后执行，不先激活主窗口，不因后续配置输入而丢弃已接受的取消动作。

## Windows 独立窗口

- Windows 使用可独立拖动、缩放的系统窗口；uTools 保留页面内模态弹窗。系统窗口启动时预建并隐藏，重复打开复用，不在同步命令中临时创建 WebView，不参与附着窗口定位。
- 主窗口是唯一业务计算和存储入口。推荐窗口只接收公共模板、结果和外观快照，回传配置、方案标识及关闭动作，不启动公共应用、不读取数据库、不接收外部排班记录。
- 窗口缩矮时由内容区负责纵向滚动，页底说明和操作必须可达；Windows 独立窗口使用占满客户区的布局及可收缩内容区，页面弹窗的内容高度跟随视口并保留普通视口单位回退。快照刷新保留实际内容区的纵向滚动和表格横向滚动，不依赖文档滚动位置。
- 原生关闭、页面关闭按钮与 Escape 只隐藏推荐窗口；关闭主窗口或退出程序结束全部窗口。推荐窗口不保存主窗口尺寸或改变主窗口锁定状态。
- 配置变更等待当前提交完成后由主窗口重新计算；使用方案同时回传当前配置，重新计算后聚焦主窗口打开原调班表单。仅打开推荐窗口不先激活主窗口。
- 会话、输入序号及快照版本过滤过期操作、关闭回执和结果。刷新结果不替换正在输入的控件，保留半成品输入、焦点及滚动位置；动态调休最大值与超限回落值同步到推荐窗，已提交业务数据及外观变化同步到打开的推荐窗口。

## 核对方式

- 定位窗口创建及关闭路由时检索原生窗口构造器、关闭事件和命令注册；定位跨窗动作时检索推荐窗口事件协议及公共推荐表单入口，不维护窗口标签或文件路径导航快照。
- 修改跨窗行为时覆盖重复打开、关闭不退出、输入与结果乱序、保存等待期间采用方案以及原生失败；采用 Mock 验证协议和表单交互，并执行项目要求的原生检查和双平台构建。
- 构建验证须确认桌面独立窗口入口已打包，uTools 包不包含桌面代码；原生窗口实际拖动、缩放和关闭行为未实测时明确报告。
